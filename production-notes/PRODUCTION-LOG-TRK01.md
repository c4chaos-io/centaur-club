## How it was made (the reusable method)

1. Map the music first. Signal-check the track before any image
   exists, then let measured moments assign the panels.
2. Stills before video. Every shot composed and locked as a
   still first; video briefs written against a locked frame.
3. The character package rides every generation. No naked start
   frames, ever. One take without it shrank a co-star into a
   small cat, and that lesson only needed teaching once.
4. Fix the still first, then animate it. Never animate a
   defective source frame.
5. One variable per regeneration. A fix order names one defect;
   the next take changes that one thing.
6. Audit from frames and zoom crops, never from vibes. Identity,
   eye order, and small props are judged at crop.
7. The Director's eye is the verdict of record. The audit
   recommends; the lock decides.
8. Minor fixes go to the edit lane. Exposure ramps, fades, and
   speed changes are post work, not a reason to re-roll a
   passing performance.
9. File everything. Every take's audit, verdict, and accepted
   deviations stay in the storyboard document as history.

Generation laws proven on this production: frontal framing
protects identity and profiles grow muzzles; eye order flips
silently between takes, so crop-check it every time; camera
travel is bounded by keyframes, never by adjectives; too many
references outvote the start frame; an exposure ramp built into
every take is an edit problem, not a prompt problem.
